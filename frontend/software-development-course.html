Course Materials

Module 1: Introduction to Software Development

Learn the fundamentals of software development, how software is created, the role of a software developer and the basic stages involved in developing software applications.

Start Module 1

Module 2: HTML — Building Web Page Structure

Learn how HTML is used to create the structure of web pages. Understand elements, tags, attributes, headings, paragraphs, links, images, lists, forms and basic page organization.

Start Module 2

Module 3: CSS — Styling Web Pages

Learn how CSS is used to style and design web pages. Work with selectors, colors, typography, spacing, borders, layouts, responsive design and other essential styling techniques.

Start Module 3

Module 4: JavaScript Fundamentals

Learn the fundamentals of JavaScript and how it adds interactivity and functionality to websites. Topics include variables, data types, operators, functions, conditions, loops, arrays and basic programming concepts.

Start Module 4

Module 5: JavaScript & Web Page Interaction

Learn how JavaScript interacts with HTML and CSS. Work with the DOM, events, buttons, forms and other techniques for creating interactive web pages.

Start Module 5

Module 6: Development Tools & Workflow

Learn how to work with development environments and essential developer tools. Set up your workspace, organize project files and use tools such as Visual Studio Code and browser developer tools.

Start Module 6

Module 7: Git & GitHub

Learn the fundamentals of version control and how Git and GitHub are used to manage software projects, track changes and collaborate with other developers.

Start Module 7

Module 8: Responsive Web Development

Learn how to create websites that work effectively across different screen sizes and devices using responsive design techniques.

Start Module 8

Module 9: Backend Development with Node.js

Start Module 9

Module 10: Express.js & APIs

Start Module 10

Module 11: Databases & MongoDB

Learn the fundamentals of databases and how MongoDB can be used to store and manage application data.

Start Module 11

Module 12: Full-Stack Web Development

Bring frontend and backend concepts together to understand how complete web applications are developed, connected and deployed.
